## Описание проекта
Адаптивная панель администратора («Мониторинг системы»), построенная на **Bootstrap 5** и чистом **JavaScript (ES6+)**. Реализует динамическую загрузку показателей и журнала событий из JSON-файлов, валидацию формы в реальном времени и интерактивный UI (Toast-уведомления, модальные окна, микроанимации).

## Стек технологий
* **HTML5, CSS3, Bootstrap 5.3** (Сетка, Navbar, Cards, Table, Modal, Toast, Badges)
* **JavaScript (ES6+)** (Fetch API, async/await, DOM, Regex)
* **JSON** (Хранение метрик, записей и уведомлений)

## Реализованный функционал
1. **Адаптивная верстка**: корректное отображение на ПК, планшетах и смартфонах.
2. **Динамический рендеринг (Fetch API)**: автозагрузка показателей, строк таблицы из `dataset/dashboard.json` и уведомлений из `dataset/notifications.json`.
3. **Валидация и добавление данных**: проверка заполнения полей и формата Email в модальном окне, добавление записи в таблицу без перезагрузки страницы.
4. **Интерактивность и UX**: вызов Toast-уведомления при клике на строку таблицы, динамические цветные статусы, микроанимации при наведении на карточки и кастомный скроллбар.

## Инструкция по запуску
Из-за правил безопасности браузера (CORS) проект нужно запускать через локальный сервер:
* **VS Code**: Клик правой кнопкой по `index.html` **Open in Integrated Browser**.
* **Через консоль**: Запустить `python -m http.server 8000` в папке проекта и открыть `http://localhost:8000`.
